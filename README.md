# Car Service Estimate Explainer

A Streamlit-based GenAI MVP for the Digital Product Management course project.

## Current status

Initial Streamlit application skeleton created.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Planned MVP flow

1. Enter basic vehicle details.
2. Paste a service estimate or job-card items.
3. Ask the AI to explain the estimate.
4. Receive structured decision-support information.

> The product is intended to support informed conversations with qualified service professionals, not replace professional mechanical diagnosis.
